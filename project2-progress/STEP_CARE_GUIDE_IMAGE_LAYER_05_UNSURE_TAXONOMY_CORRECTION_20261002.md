# Care Guide Image Layer 05 — Unsure Route Taxonomy Correction

Date: 2026-10-02
Project: Spatial Flow V2 / Project 2

## User screenshot feedback

The screenshot highlights the "Unsure?" block beneath the three visual care categories.

## Diagnosis

The issue is not merely spacing.

"Unsure / Need Help" was incorrectly treated as a fourth peer category beside:
- Jewelry
- Crystal Objects
- Home Pieces

That is a taxonomy error.

The first three are object categories.
"Unsure?" is an escape / support route.

Presenting it as category 04 creates:
- broken visual rhythm;
- an awkward full-width empty row;
- false equivalence with real object categories;
- excessive emphasis from the large question mark;
- a composition that feels appended rather than intentional.

## Correction

The category chooser should contain only real object categories:
1. Jewelry
2. Crystal Objects
3. Home Pieces

"Unsure / Need Help" should move outside the category grid and become a secondary support strip / text route below the chooser.

It should:
- remain easy to find;
- use lower visual emphasis than object categories;
- not use a giant question mark;
- not receive a category number;
- route directly to Support.
