# Step 4G — Shop Hybrid V2 only marginally improved; still rejected

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User verdict

User feedback on `spatial-flow-shop-hybrid-v2-compositional-reset.html`:

> 稍微好了一点，还是不满意

Interpretation:
- V2 improved over the rejected 3/10 V1;
- improvement is not enough to justify incremental polish;
- the visual mother direction still misses the user's target.

## Failure diagnosis

1. Still too section-driven
   - opening;
   - current edit;
   - browse;
   - archive;
   remain visibly stacked modules.

2. Still too much "website composition"
   - the page is more authored than V1, but the authored devices are still arranged as recognizable web sections rather than one continuous commercial spatial experience.

3. Current Edit still behaves like three feature cards
   - despite open styling, the 1+2 product composition is still a familiar merchandising pattern.

4. Browse still behaves like an interface demonstration
   - list + reactive stage is more interesting than tabs, but still reads as a designed mechanism rather than a natural part of the shop.

5. Abstract CSS/SVG objects became a visible design device
   - they prevent stock-photography cheating, but risk making the page feel like a concept study instead of a mature commerce destination.

6. Too explanatory
   - multiple labels and statements explain what the Shop is doing.
   - the desired experience should reveal itself with less narration.

7. Discovery and Archive remain separated
   - the landing experience should more convincingly dissolve into the real product archive instead of handing off between distinct blocks.

## Decision

Do not polish V2.

Next direction must reduce:
- section boundaries;
- explanatory copy;
- visible UI mechanisms;
- feature-card logic.

Next direction should test:
- one continuous spatial/commercial field;
- archive content appearing earlier;
- editorial hierarchy embedded inside the catalog rather than sitting above it;
- discovery created through composition/cropping/order rather than explicit interaction widgets;
- real product/archive utility emerging naturally from the same field.

Status:
SHOP HYBRID V2 = REJECTED / MOTHER DIRECTION STILL OPEN.
