# Care Guide — Image Layer Direction Exploration

Date: 2026-10-02
Project: Spatial Flow V2 / Project 2

## User feedback

Filtered Category 04 is directionally acceptable.

User asks whether the Care Guide should add images.

## Judgment

Images can materially improve this page, but only if they serve category recognition / material understanding.

The page should NOT become image-heavy editorial storytelling.

Recommended image roles:
1. Category recognition image — Jewelry / Crystal Objects / Home Pieces each gets one strong real-product or real-material visual.
2. Optional active-category detail image — one close material / handling crop inside the selected panel.
3. No decorative image required for Unsure / Support.

Avoid:
- generic stock lifestyle imagery;
- repeated mood photography;
- invented materials/products;
- image galleries that push care instructions below the fold;
- using images as a substitute for actual care guidance.

## Preferred hierarchy

Category chooser:
- image + category name + short descriptor;
- image is functional recognition, not decoration.

Selected category:
- one optional contextual/detail image;
- instructions remain primary.

## Content source requirement

Production should prefer real Spatial Flow product / material photography.
If real imagery is not yet available for a category, use a clearly temporary placeholder during preview rather than fabricating product reality.
