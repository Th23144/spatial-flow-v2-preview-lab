## Cross-project principles that SHOULD transfer to Spatial Flow Shop

1. Intelligent Minimalism
   - low noise;
   - high control;
   - strong art direction;
   - quiet but startling;
   - long-term usability over novelty.

2. Design Hook > Product Hook
   - the page must remain convincing with ordinary product imagery;
   - layout, proportion, hierarchy and interaction must carry authorship.

3. Static-first admission
   - the Shop landing layer must be strong with motion disabled;
   - motion can elevate but not rescue weak composition.

4. Object > UI
   - products/materials/room imagery should dominate;
   - controls, filters and navigation should recede until needed.

5. One decisive focal point per visual layer
   - avoid simultaneous competition among giant typography, large products, metadata, color blocks and motion.

6. Active Whitespace / Quiet Pressure / Monumental Restraint
   - whitespace must create tension and scale, not emptiness;
   - avoid conventional luxury-template softness without structural force.

7. Decisive boundaries
   - avoid card walls, glassmorphism, vague floating panels and decorative chrome;
   - relationships may be subtle but must be explicit.

8. Typography discipline
   - clear hierarchy, precise placement, readable operational data;
   - typography supports the object rather than continuously becoming the hero.

9. Motion as state / relationship
   - motion should reveal selection, reorganization, focus, continuity or discovery;
   - avoid decorative ambient motion.

10. Discovery as product capability
   - the Shop should reveal deeper routes naturally;
   - users should feel there is another meaningful layer to inspect.

11. Shared grammar / variable composition
   - Shop landing, archive, product detail, Studio and mobile do not need identical layouts;
   - unity comes from spacing, object treatment, type rhythm, motion weight and interaction philosophy.

12. Mobile re-composition
   - do not vertically stack desktop composition;
   - mobile must preserve the same creative point of view with a new composition.

13. Catalog independence
   - the design must survive changing products, colors, materials and counts;
   - no layout should depend on a few unusually beautiful SKUs.

14. Abstract Eastern restraint only
   - if any Eastern sensibility appears, it must come from proportion, distance, ritual, silence and order;
   - no literal decorative motifs.

15. Authorship
   - the result must not be a logo-swappable luxury ecommerce template.

16. Reference mechanism, not visual collage
   - A24 / Palmer / Squarespace / Everyday / Dropbox etc. are mechanism references;
   - extract why they work, not what they look like.

17. Strict final gate
   - if the static composition is generic, the design hook is weak, or the page becomes a normal ecommerce template, kill the candidate before showing the user.

## Principles that transfer ONLY PARTIALLY

1. Direct manipulation / object-as-interface
   - highly relevant to Studio;
   - for Shop, it may inspire browsing/view-state changes, but should not turn product discovery into a configurator.

2. Progressive disclosure
   - relevant to filter/sort/discovery states;
   - must not hide critical commerce information such as price, availability or obvious route to product details.

3. State choreography
   - relevant if Shop supports multiple discovery views (object / room / material);
   - should remain simpler than the Studio interaction model.

4. Experiential continuity
   - relevant between Shop landing -> archive -> product detail -> Studio;
   - implementation must not destabilize WooCommerce routing or usability.

## DIY-specific rules that should NOT be copied literally into Shop

- bracelet sequence manipulation;
- bead/material direct editing;
- wrist / fit / engraving tool hierarchy;
- builder trays / active-making workspace;
- material inspection as the dominant page role;
- Studio-specific Focus / Preview / Build state logic.

These remain useful as conceptual interaction references only.

## Project-specific correction for commerce

Spatial Flow Shop is a commercial destination. Therefore:
- price and product identity must remain easy to scan;
- filter / sort / pagination must stay functionally obvious;
- the archive cannot become an art installation that damages shopping efficiency;
- commerce should be quiet, not hidden.

The target is:
`low-noise commerce with strong authorship`,
not
`commerce disguised until the user is confused`.
