## Direction implemented

Wishlist is treated as a commerce utility inside the accepted Spatial Flow system.

### Rejoined visual language
- warm paper / near-black / terracotta / stone palette;
- restrained Cormorant + operational sans / mono hierarchy;
- open 4:5 product imagery;
- micro editorial references;
- Placement-style notes;
- open product-grid rhythm aligned with Shop / Related Products;
- dark editorial Footer approximation;
- no card wall;
- no separate About-derived visual world.

### Motion policy applied
Removed:
- ticker;
- staged hero reveal;
- IntersectionObserver row reveals;
- scroll choreography.

Retained only:
- slight image scale / saturation response;
- Saved heart color response;
- button hover feedback.

### Functional hierarchy preserved
- product image / identity;
- price;
- stock state;
- View Piece;
- Add to Bag;
- Remove from Saved;
- Continue Browsing;
- View Bag;
- empty state.

Production note:
- YITH must remain authoritative for saved state.
- WooCommerce must remain authoritative for product, price, stock and cart behavior.
- Prototype does not authorize production changes.
