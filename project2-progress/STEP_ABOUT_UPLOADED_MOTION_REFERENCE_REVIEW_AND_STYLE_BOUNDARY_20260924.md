# About Us — Uploaded Motion Reference Review + Spatial Flow Style Boundary

Date: 2026-09-24
Project: Spatial Flow V2 / Project 2

## User clarification

The user supplied three motion/design-study videos for reference only. They include tutorial content and are not direct design specifications.

Critical added constraint:
advanced motion / interaction is welcome only if it does NOT drift materially away from the established Spatial Flow visual language.

Therefore:
- do not import another site's visual identity;
- do not turn About Us into a generic Awwwards / portfolio showcase;
- borrow interaction grammar and narrative mechanics, not surface styling.

## Reference observations

### Reference A — futuristic commerce / character-led site tutorial
Useful mechanisms:
- one dominant full-screen visual anchor;
- product / story content layered around a strong visual subject;
- state changes and interaction make the page feel alive;
- high visual hierarchy and obvious first-screen attraction.

Not suitable to copy directly:
- neon / high-saturation fashion-tech palette;
- aggressive condensed display typography;
- game / streetwear / futuristic commercial tone;
- spectacle-first density.

### Reference B — ocean scroll-controlled hero
Most relevant structural lesson for Spatial Flow:
- full-screen environmental visual;
- typography/UI remains calm while the world behind it changes;
- scroll acts as a master narrative state;
- transition from above-water to underwater creates a literal experiential story rather than decorative animation;
- motion is coherent because one visual metaphor owns the entire sequence.

This is highly transferable as a motion principle, but not as an ocean aesthetic.

### Reference C — AIGC dynamic portfolio / motion study
Useful mechanisms:
- image-to-image state transformation;
- compositing multiple visual states into one evolving subject;
- typography treated as motion material;
- masking / reveal / distortion / controlled transformation;
- scene transitions tied to a visual concept.

Not suitable to copy directly:
- high-contrast black/orange graphic identity;
- poster / motion-design-showreel language;
- kinetic density as an end in itself.

## Spatial Flow About direction

Potentially appropriate:
- cinematic first-screen motion;
- scroll-linked story progression;
- subtle parallax / masking;
- material/light transitions;
- object-to-space transformation;
- controlled typography reveal;
- one or two high-impact interactive scenes;
- restrained cursor response where it clarifies spatial relationship.

Must remain Spatial Flow:
- warm paper / dark ink / clay / sage;
- Cormorant Garamond / Inter / JetBrains Mono roles;
- editorial negative space;
- tactile material / object / room imagery;
- quiet pacing rather than hyperactive motion;
- readable About content;
- brand story remains comprehensible without motion.

## Design principle

The correct target is:
"Spatial Flow with a higher expressive ceiling"
NOT
"an impressive motion-design website wearing Spatial Flow copy."

Motion must have a narrative owner:
- Origin / why Spatial Flow exists;
- Object → Space;
- Material → Light / texture;
- Placement → relationship;
- Shop / Journal / Studio → what the brand actually does.
