# Step 4G — Spatial Flow Shop Design Grammar V1

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## 0. Page role

The Shop is Spatial Flow's commercial home.

It is:
- a restrained landing surface;
- a discovery system;
- a real WooCommerce archive.

It is NOT:
- the global Spatial Flow homepage;
- a generic ecommerce homepage;
- a pure PLP;
- a magazine;
- a configurator;
- a Studio clone.

## 1. Core design thesis

`Low-noise commerce with strong authorship.`

The page should first feel designed, then clearly shoppable.

Commerce is quiet, never hidden.

## 2. First-screen rule

The opening must contain one decisive visual event.

Preferred focal hierarchy:
1. one object / object group / room-object relationship;
2. restrained shop identity;
3. one primary route into the commercial field.

Do not use:
- data-stat hero;
- 3-4 equal mosaic cards;
- giant title + giant product simultaneously;
- multiple CTA buttons;
- category pill wall.

### Parameter target
- primary object/image footprint: ~42–58% of desktop visual field;
- text footprint: ~18–28%;
- active whitespace: ~25–38%;
- visible primary CTA count: 1;
- secondary textual route: maximum 1;
- first-screen copy: preferably <= 55 words excluding micro-metadata.

## 3. Typography

Typography frames the object; it does not continuously become the object.

- Cormorant Garamond remains the editorial display language.
- Inter remains operational/body language.
- mono/micro-label language may remain where already established.
- giant typography is exceptional, not default.
- product price/reference/availability must remain instantly scannable.

### Desktop range
- primary opening title: ~54–76px preferred;
- section titles: ~36–52px;
- product titles: preserve current accepted scale;
- micro labels: ~9–11px.

### Mobile range
- opening title: ~38–52px;
- section titles: ~32–42px;
- avoid multi-line 70px pseudo-editorial hero text.

## 4. Object treatment

Objects must survive the "ordinary SKU test."

The system must still work if:
- product imagery is mediocre;
- products are all dark;
- products are all transparent/light;
- product colors conflict;
- product count changes.

Therefore:
- composition cannot depend on gemstone color;
- no product-specific background palette as the main system;
- image crop/proportion and surrounding space carry hierarchy;
- 4:5 remains the preferred product-image grammar where appropriate.

## 5. Whitespace

Whitespace is structural.

Use it to create:
- distance before archive;
- pressure around one object;
- clear threshold between discovery and commerce;
- pauses between browsing states.

Do not create:
- random empty vertical bands;
- excessive hero height with no structural event;
- "luxury" spacing that merely makes the page longer.

### Parameter target
- landing layer before archive: roughly 1.1–1.7 desktop viewport heights total;
- avoid >2 viewport heights before users can reach the real product archive;
- section-to-section vertical rhythm should intentionally alternate pressure / pause.

## 6. Boundaries / surfaces

Default:
- open field;
- hairline rule;
- crop;
- tonal surface shift.

Exceptional:
- dark field;
- enclosed panel;
- rounded container.

Avoid:
- card walls;
- generic white rounded cards;
- glass panels;
- floating filter cards;
- soft shadow stacks.

Border radius:
- generally 0–4px;
- only product/media semantics may justify more.

## 7. Color

Current Project 2 palette may remain:
- warm paper;
- near-black ink;
- terracotta;
- stone green / bluestone.

But these are not mandatory aesthetic laws.

Rule:
- color supports structure;
- object colors may vary;
- interface should not compete with catalog content.

No neon/glow/gradient-led composition.

## 8. Discovery grammar

Spatial Flow Shop needs discovery richer than category tabs.

Candidate discovery axes:
- Object;
- Space;
- Material;
- Custom Studio.

These are NOT four permanent giant panels.

They are a compact discovery vocabulary.

The chosen axis may reorganize one shared visual field.

### State-change rule
A state change should alter:
- grouping;
- focal object;
- image crop;
- metadata emphasis;
- visible destinations.

It should NOT default to:
- opening a dashboard panel;
- stacking chips;
- exposing a large inspector.

## 9. Archive threshold

The moment the user enters the real archive must be unmistakable.

Use:
- a strong rule / alignment change / density shift;
- clear archive title;
- real product count;
- Filter / Sort.

The current accepted product grid, pagination and closing note are protected assets unless a later user decision reopens them.

The archive should feel like:
`the discovery field settles into a usable catalog`.

## 10. Product grid

Preserve current accepted strengths:
- desktop open multi-column grid;
- mobile 2-column normal grid;
- restrained metadata;
- real WooCommerce truth;
- no card shells;
- wishlist/commerce actions must remain usable.

Do not over-editorialize every card.

One product card should remain a product card.

## 11. Custom Studio placement

Studio is a signature capability, not a marketing campaign.

In Shop:
- show it once;
- give it high conceptual value;
- low promotional noise.

Preferred treatment:
- discovery state / threshold / one focused interlude before archive;
- one sentence;
- one entry action;
- possibly one material/object signal.

Avoid:
- giant black promo banner;
- full mini-homepage;
- repeated Studio CTA.

## 12. Motion

Static composition must pass first.

Allowed high-value motion:
- focus/unfocus;
- state switch;
- object continuation;
- crop shift;
- reorder;
- reveal;
- settle;
- filter result transition.

Avoid:
- ambient floating;
- cursor chase;
- parallax-for-parallax;
- looping decoration;
- bounce-heavy UI.

### Motion target
- most state transitions: ~260–480ms;
- local feedback: ~140–220ms;
- no constant movement;
- clear peaks and pauses;
- reduced-motion path required.

## 13. Commercial clarity

Never hide:
- product identity;
- price;
- stock/availability when relevant;
- filter/sort;
- pagination;
- Add/View path.

"Quiet commerce" means visual restraint.
It does not mean ambiguous shopping.

## 14. Mobile

Mobile is a new composition.

Required:
- one first-screen focal event;
- discovery axes remain thumb-readable;
- no desktop asymmetry merely stacked;
- object remains first;
- filter/sort stays compact;
- product archive stays 2 columns except existing <=360 fallback;
- Studio state/interlude compresses to one decisive event.

## 15. Authorship test

Remove:
- logo;
- beautiful SKU;
- motion.

The page must still feel specifically Spatial Flow through:
- object/space relationship;
- disciplined typography;
- editorial metadata restraint;
- spatial discovery logic;
- threshold into archive;
- quiet pressure.

If it becomes a generic jewelry/furniture Shopify page, reject it.

## 16. Protected current Shop assets

Do not casually rebuild:
- filter/sort runtime behavior;
- product cards;
- pagination;
- Closing Note;
- WooCommerce dynamic ownership;
- accepted desktop/mobile archive rhythm.

The new design work should concentrate primarily on:
- opening layer;
- discovery layer;
- Custom Studio integration;
- transition into the archive.
