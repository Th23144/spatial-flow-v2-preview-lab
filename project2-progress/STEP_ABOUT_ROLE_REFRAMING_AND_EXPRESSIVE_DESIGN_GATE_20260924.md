# About Us — Role Reframing and Expressive Design Gate

Date: 2026-09-24
Project: Spatial Flow V2 / Project 2

## User clarification

The user's hesitation about the current About Us candidate is not primarily a typography, spacing, image, or layout complaint.

The deeper question is whether the page is fulfilling the correct product role.

The user has recently been studying highly expressive digital design in a separate design-learning workflow before future Global Home / Light Home work. That exposure includes video-led storytelling, advanced motion, immersive interaction, and high-engagement personal/brand introductions.

This has raised a valid design question for Spatial Flow:
if a visitor deliberately opens About Us, should the page do more than present a restrained editorial manifesto? Should it actively tell the brand story and create a more memorable, visually engaging experience?

## Product-role correction

About Us must first answer:
- who / what Spatial Flow is;
- why it exists;
- what it actually does;
- what point of view or method distinguishes it;
- what the visitor should understand about the brand after reading.

The current external-source-derived About composition is visually competent but leans heavily toward brand manifesto / aesthetic positioning. It under-serves direct brand explanation.

## Design gate

Do NOT immediately revise the current About candidate.

First decide the correct expressive ceiling for About Us.

Working direction to evaluate:
- About may legitimately be more expressive and interaction-rich than utility pages such as Contact / FAQ / Policy / Track Order;
- motion / video / scroll choreography should serve narrative and brand comprehension, not exist as spectacle only;
- the page should retain readable brand substance even if visual expression is pushed significantly further;
- advanced interaction is allowed to become part of the page's storytelling language if it remains performant, accessible, and coherent with Spatial Flow;
- do not copy showcase/portfolio effects mechanically.

The user may provide reference videos from the design-learning project. If supplied, analyze the underlying motion / interaction / storytelling mechanisms rather than merely imitating surface aesthetics.

## Professional-assistance requirement

The user explicitly requires independent professional judgment rather than automatic agreement.

Future design decisions should distinguish:
- valid user preference;
- objectively weak UX / IA / implementation;
- subjective taste;
- high-impact but inappropriate visual spectacle;
- expressive techniques that genuinely improve the product.
