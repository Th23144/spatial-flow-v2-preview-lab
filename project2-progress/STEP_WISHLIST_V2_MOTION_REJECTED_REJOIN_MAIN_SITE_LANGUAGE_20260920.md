# Wishlist V2 Motion Study rejected — motion removed from design authority

Date: 2026-09-20
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User verdict

User feedback on `spatial-flow-wishlist-v2-motion-study.html`:

> 动起来好诡异啊，确实有点不配套，还有页面我觉得也差点意思，没有网站整体的那种风格

## Interpretation

The Wishlist motion study is rejected.

Two distinct problems were identified:

1. Motion mismatch
   - The About Us ticker / reveal language does not transfer naturally to Wishlist.
   - Motion makes the utility page feel staged rather than native to the commerce site.
   - Continuous ticker especially feels semantically forced on a private Saved/Wishlist surface.

2. Site-language mismatch
   - The Wishlist page does not sufficiently inherit the accepted Spatial Flow visual system.
   - It feels like a separate editorial concept rather than a page belonging to the already-approved commerce site.

## Decision

Do not continue tuning the motion study.

For Wishlist:
- remove marquee/ticker;
- remove obvious entrance choreography;
- keep only native micro-interaction where useful (hover/focus/state feedback);
- re-anchor the page to the accepted main-site language from Header V2, Footer V2, Single Product, Shop archive, Cart and Checkout;
- retain YITH/WooCommerce as functional owners;
- keep the old Wishlist static reference only for information hierarchy, not as a visual authority.

## New direction

Wishlist should feel like:
`A SAVED-OBJECTS UTILITY INSIDE THE SAME SPATIAL FLOW COMMERCE SYSTEM`

Not:
- a mini editorial feature page;
- an About Us derivative;
- a separate visual world.

Status:
WISHLIST V2 MOTION STUDY = REJECTED.
MOTION = DE-EMPHASIZED.
VISUAL LANGUAGE = MUST REJOIN ACCEPTED MAIN-SITE SYSTEM.
