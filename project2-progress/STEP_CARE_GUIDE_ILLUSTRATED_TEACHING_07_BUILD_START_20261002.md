# Care Guide 07 — Illustrated Teaching Build Start

Date: 2026-10-02
Project: Spatial Flow V2 / Project 2

## Trigger

User approved moving beyond the 06 text-heavy care panels.

## Goal

Build a new temporary Care Guide candidate that keeps the successful category-first / single-page interaction, but turns each selected category into a visual teaching layout.

## Core correction

The page should no longer behave like:
- category selector + long text reference.

It should behave like:
- category selector;
- visual teaching modules;
- image + concise explanation;
- optional caution / material note;
- support.

Images must participate in instruction, not merely decorate the page.

## Structural baseline retained

- one Care Guide page;
- three object categories:
  1. Jewelry
  2. Crystal Objects
  3. Home Pieces
- only the selected category is shown;
- Support remains outside the category taxonomy.

## Teaching-module pattern

Each active category should use modular blocks such as:
- Everyday care / Handling
- Cleaning
- Storage / Placement
- What to avoid / Material variation

Each module includes:
- one visual anchor;
- one clear teaching heading;
- concise editable body copy;
- optional small reminder / note.

## Image policy for this prototype

- temporary reference imagery is allowed only to test layout and visual weight;
- no temporary image is to be presented as a real Spatial Flow product;
- eventual production mapping must use real Spatial Flow product/material photography or verified owned/licensed assets.

## Guardrails

- no fabricated products;
- no fabricated care claims;
- no image-heavy editorial magazine treatment;
- no commerce-card grid;
- no production mapping.
