## User authorization

User approved starting the primary mother direction after the research reset.

## Locked mother direction

`COUNT-RESPONSIVE CURATION BOARD`

The saved-object count becomes a composition input rather than a simple numeric label.

This prototype studies the 4-object state only.

## Static-first rule

This pass must stand without motion.

No:
- marquee;
- scroll reveal;
- object drift;
- focus-swap interaction;
- decorative cursor effects.

Only quiet hover/focus affordances may exist, but the design must remain complete as a static frame.

## Four-object composition rule

For exactly four saved objects:
- do not render four equal columns;
- use a strict hidden grid with unequal object scale and offset;
- allow one focal object, two counterweights, one quieter anchor;
- keep price, stock and product identity visible;
- use whitespace as active structure rather than empty padding;
- avoid visible card containers;
- preserve a direct path to View / Add to Bag / Remove.

## Mobile recomposition

Mobile is not a vertical stack of the desktop board.

For the four-object state:
- one object establishes the first focal field;
- two objects form a compact paired middle state;
- one final object closes the composition;
- actions stay reachable without hover.

## Admission gate before showing

Kill internally if:
- it reads like Shop Grid;
- it reads like a jewellery template after changing the logo;
- the first screen is intro-only;
- product hierarchy becomes unclear;
- irregularity reads as random masonry;
- the static frame needs motion to become interesting.
