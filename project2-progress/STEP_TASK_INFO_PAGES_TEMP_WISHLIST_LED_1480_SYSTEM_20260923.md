## Temporary shared visual rule

Use the Wishlist page as the current reference language for these pages:

1. Header / Footer shell:
   - 1720px system / broader global shell.

2. Main page body:
   - `--max: 1480px`
   - plus internal horizontal padding.

3. Visual language:
   - preserve the Wishlist Harmonized V1 editorial hierarchy, spacing logic, negative-space discipline, typography balance, boundary treatment, action restraint, and mobile quality.
   - do NOT clone Wishlist composition literally where the page function differs.
   - adapt each page's structure to its actual function while keeping the same design generation.

4. Functional ownership:
   - visual harmonization does not replace real WordPress / WooCommerce / YITH / page-template ownership.
   - dynamic data and existing backend editability remain authoritative.
