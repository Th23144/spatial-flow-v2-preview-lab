# Step 4G — Shop grammar addendum after sibling-branch correction

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## Superseded point

The previous Shop Design Grammar / Interaction Contract allowed:

`OBJECT / SPACE / MATERIAL / CUSTOM`

as candidate in-Shop discovery states.

This is now superseded.

## Correct Shop discovery vocabulary

Shop-owned discovery states:
- OBJECT
- SPACE
- MATERIAL

These are all legitimate ways of browsing the commerce catalog.

DIY / Custom Studio is NOT a Shop-owned discovery state.

## Sibling route rule

DIY / Studio may appear:
- in the shared global Header;
- in a restrained secondary cross-link;
- in Footer / related destination areas;

but never as:
- the fourth tab of Shop discovery;
- a Shop-owned promotional feature section;
- the climax of the Shop Landing;
- a mini builder embedded into the Shop Landing.

## Shop mother direction, corrected

```text
OPENING OBJECT FIELD
        ↓
DISCOVERY SEAM
OBJECT / SPACE / MATERIAL
        ↓
ARCHIVE THRESHOLD
        ↓
THE QUIET ARCHIVE
Filter / Sort / Grid / Pagination
        ↓
Closing Note
```
