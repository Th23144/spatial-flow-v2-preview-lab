# About Us Planning — Future Commerce Thesis Exploration

Date: 2026-09-26
Project: Spatial Flow V2 / Project 2

## Purpose

Move from:
"what is structurally wrong with current ecommerce for culturally and materially rich objects?"

to:
"what does Spatial Flow believe the better future should look like?"

This stage defines the brand's strategic thesis before any About copy, page structure, motion design, or HTML.

## Validated prior foundation

The current working core is:
- preserve the specificity and richness of real objects in digital commerce;
- reconnect objects with context, relationship, configuration, use, and meaning;
- move users from passive purchase toward informed participation;
- keep Spatial Flow distinct from Ink & East while allowing a deep ecosystem partnership;
- treat crystal / bracelet DIY as current evidence, not the final category boundary.

## Questions for this phase

1. What should replace the standard "catalog → PDP → add to cart" model for these categories?
2. What should a user be able to understand before purchase?
3. What should a user be able to manipulate / configure / inspect before purchase?
4. How should culture, provenance, material, space, use, and care remain attached to the object?
5. What should remain human / editorial rather than automated?
6. What experience should persist after checkout?
7. Which parts are true brand principles versus implementation features?
