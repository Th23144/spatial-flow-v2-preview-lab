## Result

The V4 candidate implements the reset design method:

- Wishlist V1 functional hierarchy preserved conceptually;
- old/current Home excluded from visual authority;
- no Shop-grid reuse;
- no About-derived marquee or scroll reveal;
- high-score reference mechanisms translated into a Wishlist-specific composition;
- one large selected-object field paired with a numbered saved-object index;
- index hover/focus changes the selected object image and placement note;
- motion represents real selection state only;
- price / stock remain visible;
- View Piece / Add to Bag / Remove remain explicit for the active object;
- mobile recomposes into a direct saved-object list with 4:5 thumbnails;
- empty state remains calm and secondary.

## Design hook

`PRIVATE INDEX / OBJECT FOCUS`

This is intended to make Wishlist feel like a authored saved-object instrument rather than:
- another Shop archive;
- a Woo table;
- an editorial About page;
- or a generic card grid.
