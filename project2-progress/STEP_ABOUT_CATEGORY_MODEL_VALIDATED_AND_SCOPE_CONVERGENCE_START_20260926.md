# About Us Planning — Category Contradictions Validated, Scope Convergence Begins

Date: 2026-09-26
Project: Spatial Flow V2 / Project 2

## User validation

The user strongly confirms that the current category-contradiction model matches the intended thinking behind Spatial Flow.

Validated strategic direction:
- Spatial Flow should not be defined by today's crystal inventory;
- the deeper problem is how culturally rich, materially sensitive, craft-based, non-standard physical objects are flattened by standardized ecommerce;
- knowledge / cultural context and transaction are often separated;
- objects are usually isolated from configuration, use, space, provenance, and relationship;
- Spatial Flow's long-term differentiation should be built around how it treats and presents objects, not around one product category.

## Next planning phase

Begin **scope convergence**.

The purpose is to decide which structural problems Spatial Flow should actively own and solve, versus which should remain:
- partner responsibilities;
- future capabilities;
- supporting disciplines;
- out of scope.

The brand must not attempt to solve every problem in culture, commerce, craft, authenticity, education, and spatial practice simultaneously.

## Working convergence principle

The likely Spatial Flow core should be small enough to stay legible but broad enough to survive product-category expansion.

Candidate core responsibilities to test:
1. preserve material / object specificity in digital commerce;
2. reconnect objects with context, meaning, configuration, and use;
3. create a continuous path from understanding → choosing → configuring → owning / using.

Supporting responsibilities may include:
- provenance / maker transparency;
- care;
- cultural interpretation;
- spatial guidance;
- service;
- collaboration with Ink & East.

These are not yet frozen.
