# Wishlist V8 rejected — too close to Shop/catalog

Date: 2026-09-20
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User verdict

User feedback on Wishlist V8:

> 感觉像是商城展示页呢

## Diagnosis

V8 is rejected.

The external luxury-reference research was directionally useful, but the synthesis copied the wrong layer:
- 3-column uniform image grid;
- availability filter rail;
- view-mode controls;
- full-width Add to Bag actions;
- repeated card rhythm.

Together these make the page read as a Shop / product listing page rather than a saved-items destination.

## Correction

Wishlist must communicate `post-discovery`, not `discovery`.

Therefore the next direction must:
- remove catalog filters and view toggles;
- reduce merchandising pressure;
- avoid equal repeated product-card cadence;
- keep Add to Bag secondary rather than the dominant repeated black CTA;
- make the saved state / personal shortlist more apparent;
- retain product truth (price, stock, actions) without turning the page into another archive.

## Next visual direction

Use a `PERSONAL SHORTLIST` composition:
- compact title + saved count;
- 2-column desktop layout built from wide editorial saved-item strips, not cards;
- each item combines a restrained 4:5 placeholder, product identity, price/stock and quiet actions in one composition;
- asymmetric spacing between rows to avoid catalog rhythm while maintaining alignment;
- no filters;
- no view switcher;
- no marketing copy sections;
- empty state remains minimal.

Status:
V8 = REJECTED.
NEXT = PERSONAL SHORTLIST / POST-DISCOVERY COMPOSITION.
