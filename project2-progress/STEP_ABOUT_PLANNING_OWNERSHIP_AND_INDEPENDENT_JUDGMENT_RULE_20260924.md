# About Us — Planning Ownership and Independent-Judgment Rule

Date: 2026-09-24
Project: Spatial Flow V2 / Project 2

## User decision

The user wants the strategic planning for About Us to remain in this current Project 2 window because this window has the deepest continuity on:
- Spatial Flow brand positioning;
- Project 2 visual history;
- accepted / rejected page decisions;
- current information-page system;
- prior About candidates;
- the relationship between the main site, journal, commerce, services, and future homepage work.

The final visual / motion production may still be executed later inside the broader Global Home / Light Home design workstream, but the About product definition and planning should be completed here first.

## Independent-judgment requirement

The user explicitly requires professional independent judgment rather than automatic agreement.

Working rule:
- do not treat user preference as automatically correct;
- distinguish product logic, UX/IA, implementation constraints, brand coherence, and subjective taste;
- when the user's direction is strong, explain why;
- when it is weak or conflicts with the product, say so clearly and propose a better alternative;
- do not soften or reverse technical/design judgment merely because the user's tone is forceful;
- remain concise, professional, and task-focused.

This is a project-collaboration rule, not a medical or personal record.

## About workstream boundary

Current window owns:
1. About Us product role;
2. narrative architecture;
3. information architecture;
4. brand-story content responsibilities;
5. motion-owner map;
6. interaction ceiling and restraint rules;
7. relationship to future Global Home / Light Home design system;
8. handoff specification for later production.

Current window does NOT yet own:
- final HTML implementation;
- production WordPress mapping;
- final motion engineering;
- final shader / 3D implementation.
