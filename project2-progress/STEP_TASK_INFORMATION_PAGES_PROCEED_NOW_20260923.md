# Task / information page design decision — proceed now

Date: 2026-09-23
Repository: `Th23144/spatial-flow-v2-preview-lab`

## Scope clarified by user

This decision applies only to task-oriented / information-oriented pages:

- Search
- 404
- Contact
- FAQ / Help
- Track Order
- Utility / Policy
- Services

It does NOT apply to:
- Global Home
- Shop Light Home
- DIY / Custom Studio entry
- other high-impact brand-defining landing pages

## Decision

These task/information pages do not need to wait for the user's separate design-learning project to reach maturity.

Reason:
- their primary job is clarity, readability, state handling and site consistency;
- they do not need to carry the full visual burden of Spatial Flow's future design ceiling;
- the external-AI direction is already visually promising enough to be used as a working base;
- future design learning should be reserved for higher-impact brand-defining pages where major rethinking has more value.

## Implementation rule

For these pages:
1. use the external-AI output as the current working design base where it is stronger;
2. blend it with the original Project-2 static-reference language;
3. preserve the current accepted global shell;
4. verify mobile layout and functional/state requirements;
5. avoid unnecessary visual complexity.
