## Visual diagnosis from current 05.1

The structural taxonomy is cleaner, but the image treatment now creates a different problem:

1. Three equal large images + labels read like a shop/category collection grid.
2. The images have too much visual weight relative to the care function.
3. Equal-width symmetry makes the page feel generic and commercially templated rather than specifically like a refined care manual.
4. Repeating the same category image again inside the selected panel is redundant and visually heavy.
5. The category chooser and active content feel like two stacked modules rather than one continuous care experience.
6. The page still asks the user to process too much layout before reaching actionable care guidance.

## Direction correction

Do not continue refining the three-card image grid.

Next pass should test a more editorial / reference-like pattern:

- left / primary area: text-led category index;
- right / secondary area: ONE contextual image field;
- hover / focus / selection changes the contextual image;
- click selects the category and opens its care guidance below;
- selected category content should not repeat the same image unless a genuinely different detail image is available;
- Support remains a separate low-emphasis route.

The goal is to make imagery behave like a material cue, not a commerce card.
