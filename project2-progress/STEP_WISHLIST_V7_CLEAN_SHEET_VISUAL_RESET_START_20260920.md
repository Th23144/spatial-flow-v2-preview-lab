## V7 design brief

Build a quiet, high-end saved-items page whose quality comes from proportion, hierarchy, alignment and restraint.

No large marketing hero.
No decorative explanatory sections.
No cards.
No rounded containers.
No real product photography.
No animation dependency.

The populated state should dominate the page immediately.

Primary structure:
1. compact page title / count / short supporting copy;
2. open editorial saved-item rows;
3. visible product identity, price, stock and actions;
4. restrained empty-state study;
5. existing global shell approximation only.
