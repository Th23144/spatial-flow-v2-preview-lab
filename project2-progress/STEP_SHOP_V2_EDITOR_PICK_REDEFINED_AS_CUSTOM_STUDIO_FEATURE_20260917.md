# Shop V2 — Editor's Pick redefined as permanent Custom Studio / DIY feature

Date: 2026-09-17

## User decision

The user clarified that, regardless of season or campaign, the single thing most worthy of prominent Shop-page emphasis is the site's bracelet Custom Studio / DIY feature.

Therefore the current rotating-product interpretation of Editor's Pick is no longer the preferred product strategy.

## Revised role of the block

The large featured block between the Shop controls and product archive should become a permanent featured entry for the Custom Studio / DIY experience.

It should function as the Shop page's primary differentiation / signature-service feature rather than as a rotating single-product promotion.

## Design principle

Preserve the strong reference geometry and editorial treatment, but reinterpret its semantic/function ownership:

- left: Custom Studio / DIY visual
- right: Custom Studio editorial copy
- primary CTA: enter/start the DIY experience
- secondary CTA: supporting explanation such as How it works / Explore materials / Studio note
- price: only if sourced from a real DIY pricing owner; otherwise do not fabricate a static price

## Ownership boundary

Do not force WooCommerce product short description, material, placement, or individual product metadata to populate this permanent feature.

The feature should ultimately be driven by the Custom Studio content/pricing owner or another explicit backend-editable integration layer, while WooCommerce remains responsible for commerce/order/payment where applicable.

## Immediate consequence

Pause further micro-polish of the existing rotating-product Editor's Pick implementation until the block is re-scoped around Custom Studio.

No code change has been made by this record.
