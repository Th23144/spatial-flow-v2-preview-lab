# Step 4G — Shop Hybrid Object Field V1 standalone prototype ready

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## Architecture applied

The prototype follows the corrected sibling-branch model:

```text
Shared Brand Home
├─ Shop light home + product archive
└─ DIY light home + builder experience
```

Shop does NOT own Studio.

Studio therefore appears only as a restrained sibling route in the shared navigation/footer context. It is not a Shop discovery state and not a promotional Shop section.

## Prototype direction

Mother direction:
`OBJECT FIELD -> ARCHIVE`

Structure:
1. Opening Object Field
2. Discovery Seam
   - OBJECT
   - SPACE
   - MATERIAL
3. Archive Threshold
4. The Quiet Archive
   - Filter
   - Sort
   - Product Grid
   - Pagination
5. Closing Note
6. Footer

## Design rules applied

- object-first opening;
- one dominant visual event;
- no stats hero;
- no card wall;
- no category-card row;
- no giant Studio banner;
- active whitespace;
- open fields and decisive rules;
- controlled state change in discovery;
- archive becomes more operational as the user moves deeper;
- existing accepted Shop archive language retained conceptually;
- mobile receives an independent composition with a 2-column normal product grid.
