# Step 4G — Home V3 strategic redesign proposal V1

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## Strategic premise

Home is no longer governed by literal 1:1 reconstruction of `preview/spatial-flow-v1.html`.

The redesign must reflect the long-term relationship:
- Spatial Flow is the current independent commerce/brand site;
- in the long-term architecture, Ink & East becomes the source-built primary content/culture platform;
- Spatial Flow becomes the supporting commerce destination / shop layer rather than trying to become the main editorial platform itself.

Therefore Home should not be:
- a generic crystal ecommerce landing page;
- a second Ink & East magazine homepage;
- a collection of rounded conversion cards;
- an oversized editorial issue index.

It should function as an **editorial-commerce gateway**:
brand thesis + product discovery + signature studio + spatial use context + concise editorial bridge.

## Accepted design language to inherit

From already-closed Project 2 surfaces:
- Header V2: editorial masthead language, real dynamic navigation, restrained UI;
- Shop: warm paper canvas, open editorial product presentation, restrained microtype/rules, compact CTAs;
- Single Product: 4:5 imagery, open sections, metadata bands, long-form editorial hierarchy, no unnecessary card framing;
- Footer V2: near-full-width dark editorial composition, compact trust rail, mobile left-aligned information flow.

## Proposed Home V3 information architecture

### 01 Opening / Brand Thesis
Large open editorial hero.
Not a stats/mosaic ecommerce hero.

Purpose:
- explain Spatial Flow in one sentence;
- route to Shop and Custom Studio;
- establish room / ritual / object positioning.

Composition:
- large serif statement left;
- one 4:5 editorial image right;
- restrained kicker, short lede, two CTAs;
- optional micro-caption / material note below image.

### 02 Three Ways In
Three editorial routes, not rounded cards:
- WEAR — jewelry / bracelets / necklaces;
- PLACE — objects for rooms / placement;
- MAKE — Custom Studio / bracelet DIY.

Purpose:
replace the current duplicated Categories + Energy Seeking logic with one clearer navigation layer.

### 03 The Edit
Real WooCommerce featured products.

Reuse:
- existing dynamic featured-product owner.

Presentation:
- open product grid;
- real image/title/price/reference/placement where available;
- no white card shells;
- desktop 4-up, mobile 2-up consistent with accepted Shop language.

### 04 Signature Studio
A major brand differentiator.

Purpose:
- make Custom Studio / bracelet DIY a signature Spatial Flow capability rather than another Shop category;
- primary CTA enters Studio;
- secondary link explains how it works.

Visual:
- one darker editorial split surface;
- material/bead composition on one side;
- concise copy on the other;
- not dependent on the frozen Shop implementation for the Home design decision.

### 05 For the Room
A concise spatial-use layer:
- Bedroom;
- Desk;
- Entrance / Threshold.

Purpose:
translate “space / ritual / environmental experience” into practical commerce discovery without turning Home into a long education portal.

Potential owner:
- current editable Home space-card owner after source audit/remapping.

### 06 Point of View
Short manifesto / philosophy layer.

Purpose:
state the Spatial Flow thesis:
objects are chosen for how they change the experience of a room and routine.

Visual:
- open two-column editorial composition;
- serif pull statement + shorter sans body;
- no white rounded philosophy card.

### 07 From Ink & East / Journal Bridge
A deliberately subordinate editorial bridge, not a full magazine issue homepage.

Purpose:
- connect the current commerce site to the future content/culture platform;
- surface 2–3 real articles when a real Journal post source exists;
- avoid hardcoded fake article content.

### 08 Dispatch
Minimal newsletter relationship layer.

Purpose:
- quieter subscription / early access / editorial note;
- not the current heavy lead-generation/guidance form.

### 09 Footer
Use the already accepted Footer V2 unchanged.

## Current Home module disposition

- commerce Hero mosaic: REPLACE;
- 500+/20+/100% stats: REMOVE;
- trust badge cards: REMOVE or compress into existing trust/footer system;
- Categories cards: MERGE into Three Ways In;
- Featured Collection: RETAIN DATA, REDESIGN presentation as The Edit;
- black Curated Space Sets: REPLACE with Signature Studio;
- What Energy Are You Seeking: MERGE / retire as a separate module;
- current Philosophy card: RETAIN SEMANTIC OWNER, REDESIGN as Point of View;
- current newsletter/guidance form: RETAIN FUNCTIONAL OWNER where valid, REDESIGN as Dispatch;
- reference TOC strip / In This Issue dominance: DO NOT adopt literally;
- reference Manifesto / Index / spatial-placement ideas: selectively inherit.

## Visual system

- canvas: warm paper / off-white;
- ink: near-black;
- accents: terracotta + stone green;
- display: Cormorant Garamond;
- body: Inter;
- micro labels: existing restrained mono/sans treatment;
- cards: exceptional, not default;
- radii: minimal;
- dividers: hairline rules;
- imagery: 4:5 / editorial crops rather than tile mosaics;
- CTA: compact rectangular editorial actions, not pills;
- desktop: wide open composition;
- mobile: independently composed, not desktop squeezed.
