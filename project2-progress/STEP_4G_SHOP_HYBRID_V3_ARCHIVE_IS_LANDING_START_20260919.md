## New mother direction

`THE ARCHIVE IS THE LANDING`

The Shop should no longer be composed as:
- Hero;
- Featured section;
- Discovery module;
- Archive.

Instead:
- the first viewport is already the product world;
- real product identity, price and object presence appear immediately;
- the opening composition uses irregular scale, crop, distance and negative space;
- as the user moves down, the same commercial field gradually regularizes into the standard WooCommerce archive;
- Filter / Sort become more explicit as the field settles;
- no visible handoff between “landing” and “archive.”

## Design constraints

- site-native Spatial Flow palette;
- no borrowed Ink & East palette;
- no generic left-copy/right-image hero;
- no tabs/panels/card walls;
- no Studio-owned section;
- no over-explanatory copy;
- no generated images;
- standalone HTML only;
- no production code changes;
- no repository static reference replacement yet.

## Admission target

The candidate must feel:
- commercial from the first screen;
- authored before it feels decorative;
- strong in static composition;
- quieter than a conventional ecommerce homepage;
- more integrated than V1/V2;
- capable of attaching directly to the existing accepted WooCommerce archive behavior.
