## Structural correction

The previous chapter-first hierarchy mixed different dimensions at the same level:
- Principles = rules
- Cleaning = action
- Materials = attribute
- Placement = context
- Support = service

The new pass separates these layers.

Target order:
1. concise Care intro;
2. category-first chooser;
3. category-specific care entry points;
4. compact general-care reference;
5. secondary material reference;
6. contextual placement guidance;
7. support.
