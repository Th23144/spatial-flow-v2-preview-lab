# Project 2 · Footer V2 Trust Rail Slim Direction Accepted · 2026-09-14

## User decision

User accepted the recommendation to retain the commercial trust content while reducing its visual weight.

## Locked direction

Keep the useful trust claims as a lightweight internal Footer rail:
- Worldwide Shipping
- 30-Day Returns
- Authentic Materials

Remove or heavily reduce the separate left-side `WHY SPATIAL FLOW / Considered objects, sent with care.` intro block because the Footer top area already carries the brand narrative.

## Design objective

The trust area should read as a quiet utility rail inside the Footer rather than a large four-column feature card.

Desktop:
- three balanced trust items only;
- lower vertical height;
- no rounded outer card;
- thin separators;
- near-full-width geometry consistent with Header V2.

Mobile:
- three compact rows;
- no large duplicated brand intro;
- materially shorter scroll length.

## Content authority

Concrete operational claims such as `30-Day Returns` and `5–9 days` must be verified against live Shipping / Refund policy before production lock. Prototype copy is not authoritative business truth.

## Next action

Produce an updated standalone Footer V2 HTML prototype with the slim trust rail. Do not write prototype code into production source.
