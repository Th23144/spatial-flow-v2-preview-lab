# Care Guide — External Candidate Rejection + Source Audit

Date: 2026-10-01
Project: Spatial Flow V2 / Project 2

## User feedback

The user reports strong dissatisfaction with the external AI candidate and considers it poor.

## Independent source audit

The candidate should NOT be accepted as the production or visual authority.

### 1. It fabricates brand / operational identity
Examples in the source include:
- "Studio open · Berlin"
- "Berlin · Kreuzberg"
- "Studio Journal"
- "studio@spatialflow.com"
- English / German support
- Thursday care calls
- free yearly studio cleaning
- shipping-label repair / cleaning workflows
- specific returns claims

These are not authorized current Spatial Flow facts.

### 2. It fabricates authoritative care rules
Examples include:
- universal handling / sunlight / cleaning rules;
- specific soap / distilled-water instructions;
- ultrasonic-cleaner prohibitions framed as universal;
- material-specific care for shale limestone, brass, marbled paper, silver, optical crystal, linen, leather;
- Berlin-window sunlight tolerance;
- product-specific condition / defect statements.

This directly violates the design brief:
do not invent new authoritative care rules for visual purposes.

### 3. It invents future / nonexistent assortment as if current
The page treats jewelry, crystal objects, home pieces, shale limestone, brass, marbled paper, linen, leather, etc. as if they are current Spatial Flow assortment / studio output.

This conflicts with the current reality and creates false brand evidence.

### 4. It drifts into a fictional studio-journal identity
The page repeatedly uses:
- studio manual;
- chapter numbers;
- studio journal;
- Berlin / Kreuzberg;
- editorial revision language;
- studio-floor authorship.

This creates a new fictional brand world rather than harmonizing the actual Spatial Flow site.

### 5. Structural over-design
The candidate contains too many editorial layers:
- intro;
- metadata toolbar;
- sticky chapter index;
- document header;
- secondary lede;
- repeated chapter rails;
- numbered chapter systems;
- materials table;
- room cards;
- extensive support section;
- journal-style revision signature.

The result risks feeling like an art-directed magazine/manual rather than a practical customer-care reference.

### 6. It overstates information hierarchy
Multiple simultaneous hierarchy systems compete:
- page title;
- document title;
- chapter numbering;
- sidebar numbering;
- chapter rail numbering;
- metadata labels;
- tables / zones / support numbering.

This makes a page whose primary job is "quickly know how to care for a product" unnecessarily ceremonious and cognitively heavy.

### 7. What is still usable
Some underlying interaction / layout ideas may be salvageable:
- a concise care index;
- clear separation between principles / cleaning / natural materials / placement / support;
- editorial typography using the accepted font system;
- responsive conversion of the index;
- a calm practical guide rather than a policy page.

These should be treated as isolated mechanisms, not a design direction to preserve wholesale.
