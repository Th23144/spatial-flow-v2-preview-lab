# Care Guide — Category-first IA Correction

Date: 2026-10-02
Project: Spatial Flow V2 / Project 2

## User correction

User points out that mature Care / Maintenance references also use clear categorization.

## Diagnosis

This is a key missing structural idea in the current Spatial Flow Care Guide.

The current candidates are still fundamentally linear editorial documents:
- intro;
- index;
- principles;
- cleaning;
- materials;
- placement;
- support.

Even with a Care Index, the user is navigating chapters rather than first identifying:
**"What am I caring for?"**

This contributes to the "strange" feeling.

## Mature-reference principle

A mature care page often acts as a **care lookup gateway**, not only a long-form article.

The category system is functional:
- users identify product / material first;
- then see the relevant care actions;
- deeper material-specific instructions are available only where needed.

## Recommended Spatial Flow taxonomy

Primary axis should be object / use category because it matches the current real WordPress content model:

- Jewelry
- Crystal Objects
- Home Pieces
- Unsure / Need Help

These are current content categories and should become the first visible care-routing layer.

Secondary care actions can live inside each category:
- Everyday care
- Cleaning
- Storage
- Placement / handling where applicable

Natural Materials should NOT compete as a same-level page chapter.
It is better treated as:
- a secondary reference layer;
- cross-category material guidance;
- or product/material-specific detail.

Placement Notes should also be demoted from a top-level equal chapter.
It belongs primarily as contextual guidance for applicable object categories, especially home / display pieces.

## Future extensibility

Do not hard-code the brand to crystals forever.

The category IA should be expandable later to additional object families without redesigning the entire page.

The architecture should support:
Object category → relevant care guidance → material-specific detail → support.

## Design implication

Next candidate should stop behaving like an editorial chapter document.

It should behave like:
1. brief care intro;
2. clear "What are you caring for?" category selector;
3. category-specific care content;
4. optional material reference;
5. support.

This preserves premium visual identity while making the page immediately understandable.
