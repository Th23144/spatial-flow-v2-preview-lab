# Care Guide Refinement 02 — "Visually enough, but feels strange" diagnosis

Date: 2026-10-02
Project: Spatial Flow V2 / Project 2

## User feedback

User's direct reaction to Refinement 02:
- visual level is sufficient;
- however the page feels "strange" / not naturally right.

## Diagnosis

The problem is no longer visual polish.

Refinement 02 over-corrected the earlier "generic info page" problem by importing too much strategic / brand-philosophy language into a utility page.

The added concepts such as:
- "Care is part of keeping"
- "After checkout"
- Handle → Clean → Place → Keep
- "The relationship does not end at checkout"

are strategically coherent with the About planning, but they make the Care Guide partially behave like a brand manifesto.

This creates a tonal mismatch:
- the upper / closing framing is conceptual and philosophical;
- the body is a practical care reference.

The user therefore experiences the page as polished but somehow unnatural.

## Correction

Do NOT solve this by adding more visual treatment or more care philosophy.

The Care Guide should remain primarily a practical, fast-to-scan customer-care reference.

Its page-specific character should come from:
- tactile / material-aware visual treatment;
- quiet rhythm;
- clear handling / cleaning / placement hierarchy;
- small care-specific labels and details;
- restrained ownership continuity in the background, not explicit manifesto statements.

The About strategic thesis should remain backstage.

## Direction for next pass

Use Wishlist-led 01 / Refinement 02 visual system as the base, but:
- remove or heavily reduce the explicit lifecycle / "after checkout" conceptual framing;
- remove manifesto-like closing language;
- make the page feel like a refined care manual through visual behavior rather than brand thesis;
- keep fast scanning and real WordPress content ownership as primary constraints.
