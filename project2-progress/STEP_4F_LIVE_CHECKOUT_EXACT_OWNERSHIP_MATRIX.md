## 3. Locked migration decisions

```text
1. The live Review input step must be removed.
2. Native Place Order remains WooCommerce-owned and belongs in Step 03.
3. Step 04 is only the server-authoritative order result.
4. Dynamic gateway rendering remains native; Crypto is not hardcoded as the only gateway.
5. V0.2.5 legacy /crypto-pay/ behavior remains untouched until a separate plugin phase.
6. Pending/on-hold result semantics must be corrected before Checkout can be completed.
7. Checkout notices must have one JavaScript/CSS presentation owner.
8. Backend Checkout copy controls must be reconnected or replaced without losing saved values.
9. Historical shared Checkout CSS must be cleaned by bounded blocks, not covered by more overrides.
10. CartFlows and WPCode are excluded from current Checkout ownership.
```
