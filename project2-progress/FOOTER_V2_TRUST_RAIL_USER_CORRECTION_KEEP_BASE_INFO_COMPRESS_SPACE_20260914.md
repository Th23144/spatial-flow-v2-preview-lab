# Footer V2 — Trust Rail user correction: keep base information, compress space

Date: 2026-09-14
Status: DESIGN DIRECTION CORRECTION / STATIC PROTOTYPE ITERATION

## User correction
The user clarified that the intention was not to remove the basic explanatory copy from the Footer trust area. If the trust area is retained, the basic information under each trust promise should remain. The requested optimization is spatial compression and lower visual weight, not content removal.

## Superseded prototype direction
R3 Ultra Light removed the descriptive copy and reduced the trust area to icon + label only. That direction is now superseded for the current prototype because it removes too much information.

## Current direction
Use the R2 information model (icon + title + concise explanatory copy for Worldwide Shipping / 30-Day Returns / Authentic Materials), but compress it materially:
- reduce vertical padding and minimum height;
- reduce icon size;
- tighten title-to-copy spacing;
- reduce copy font size/line-height moderately while keeping it readable;
- use compact three-column inline structure on desktop;
- preserve concise descriptive copy on mobile while keeping rows shallow;
- no separate WHY SPATIAL FLOW introduction block.

## Boundary
Exact operational claims such as return days or shipping times must be verified against live policies before production acceptance.

No production Footer code is changed by this record. Footer V2 remains in standalone prototype review.
