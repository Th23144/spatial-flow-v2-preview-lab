# Project 2 · Footer V2 trust rail design review · 2026-09-14

## User question

User asked whether the Footer V2 trust block shown in the prototype still has value and should be retained.

## Current design judgment

Retain the trust content, but do not treat it as a large standalone marketing card/section.

Recommended direction:

```text
keep the three proofs
→ Worldwide Shipping
→ 30-Day Returns
→ Authentic Materials

remove / reduce the separate introductory fourth cell
→ "Why Spatial Flow / Considered objects, sent with care."

compress the block into a quieter trust rail integrated with the footer
```

Reason:
- Shipping / returns / material authenticity are commercially useful reassurance for an unfamiliar ecommerce brand.
- The separate intro cell duplicates the footer brand statement and makes the trust area visually heavier than necessary.
- Premium/editorial footer quality improves if trust remains present but is demoted from a hero-like section to a restrained proof/utility rail.
- On mobile, this should remain compact and should not materially extend footer length.

## Content-safety boundary

Any quantitative operational promise (for example delivery time or return window) must remain aligned with the actual live policy and editable source. Do not fabricate or visually lock claims that operations cannot support.

## Status

Footer V2 direction remains in prototype/design review. No production source changes authorized by this record.
