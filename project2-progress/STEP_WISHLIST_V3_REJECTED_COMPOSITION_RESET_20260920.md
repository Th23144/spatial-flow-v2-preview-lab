# Wishlist V3 rejected — same-system does not mean copied Shop grid

Date: 2026-09-20
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User verdict

User feedback on Wishlist V3:

> 不行，很差劲

## Diagnosis

Wishlist V3 is rejected.

The key error was over-correcting from the motion study:
- V2 looked like a separate editorial concept;
- V3 tried to "rejoin the main site" by copying the Shop / product-card grammar too literally.

That produced a generic four-column saved-product page and weakened Wishlist's own identity.

## Important correction

`SAME SYSTEM != SAME COMPOSITION`

Wishlist should inherit:
- palette;
- type hierarchy;
- line weight;
- 4:5 image discipline where useful;
- metadata language;
- interaction restraint;
- Header/Footer shell;

but it should NOT simply become:
- a smaller Shop grid;
- another Product Archive;
- another landing page with a hero.

## New likely direction

Wishlist should be treated as a `private saved-object ledger / cabinet`:
- compact page intro, not a hero;
- linear/open saved-object records;
- stronger editorial inventory / ledger rhythm;
- image + product identity + placement + price/stock/action in one row system;
- optional larger preview/focus behavior only if it remains calm;
- no marquee;
- no scroll choreography;
- no card wall;
- no duplicated Shop archive composition.

The design should feel utility-specific while unmistakably inside Spatial Flow.

## Process correction

Do not build another full HTML blindly.

First produce 2–3 wire/composition mother directions in words/structure only, grounded in the accepted site grammar, then choose one before implementation.
