## Design method

This prototype follows the restored Project 2 non-reference design method used successfully during Checkout:

- preserve Wishlist V1 functional intent and states;
- keep YITH / WooCommerce as future runtime authorities;
- use stronger design references to set the visual ceiling;
- use accepted Project 2 pages as shared grammar / quality bar, not as composition templates;
- exclude the old/current Home from aesthetic authority.

## Mother direction

`PRIVATE INDEX / OBJECT FOCUS`

Wishlist is treated as a private object index rather than a Shop grid or generic utility table.

### Design hook
A large object-focus field is paired with a numbered saved-object index.

- one selected saved object owns the main visual field;
- the saved list itself acts as navigation / interface;
- selecting or hovering another saved object updates the focus field;
- this motion represents real state and is therefore meaningful;
- price / stock / product identity remain visible in the index;
- View / Add to Bag / Remove remain available for the active object;
- the page should still read strongly as a static screenshot.

### Reference mechanisms used
- A24: commerce destination with authored catalog behavior;
- Palmer Dinnerware: object-as-interface;
- Squarespace Foundations: controlled state changes;
- Everyday^: quiet precision / active whitespace;
- Dropbox Brand: motion explains state;
- Wishlist V1: saved-product hierarchy, actions, empty-state intent.

## Motion boundary
Allowed:
- focus-state crossfade / object swap;
- subtle hover and underline state;
- native action feedback.

Not allowed:
- marquee;
- scroll choreography;
- ambient decorative animation;
- hero entrance theatre.

## Hard constraints
- standalone HTML prototype only;
- no production changes;
- no generated imagery;
- no fake future owner in implementation planning;
- mobile recomposes into a direct saved-object list.
