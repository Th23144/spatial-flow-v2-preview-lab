```text

- real cart assignment-unit model
- quantity-aware units: quantity 3 creates three independently assignable units
- fixed Package 01..N slots derived from real assignment-unit count
- server normalization: together / separate / custom
- exactly one package assignment per unit
- Woo session persistence through update_order_review
```
