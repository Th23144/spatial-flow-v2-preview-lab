# Step 4G — Shop visual reset: color is subordinate to composition and must remain site-native

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User correction

The user clarified that color is NOT the primary lesson to take from the prior Ink & East aesthetic benchmark.

The Shop must remain consistent with Spatial Flow's existing visual system and overall site tone.

Therefore:
- do not import Ink & East's red/black palette;
- do not use color changes as a substitute for stronger composition;
- do not treat palette as the main design hook.

## What should transfer from the benchmark

Transfer:
- composition quality;
- spatial pressure;
- asymmetry with control;
- active whitespace;
- decisive focal hierarchy;
- authored section-to-section rhythm;
- controlled surprise;
- variable composition inside one system;
- strong static frames before motion.

Do NOT transfer:
- Ink & East palette;
- Ink & East-specific graphic motifs;
- its exact grid, red axis, or publication identity.

## Spatial Flow palette rule

The next Shop candidate should remain compatible with the already accepted Spatial Flow system:
- warm paper / off-white base;
- near-black ink;
- restrained terracotta accent;
- restrained stone/green accent;
- dark fields only when compositionally justified;
- no new loud palette introduced merely to create impact.

Color supports structure.
Color does not become the structure.

## Immediate consequence

The visual reset must solve the weak composition first.

If the next candidate only looks stronger because of a dramatic palette change, reject it internally.
