# Step 4G — Shop Hybrid Object Field V1 rejected; aesthetic reset against prior Ink & East benchmark

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## User verdict

The user rated the first Shop Hybrid / Object Field V1 prototype at no more than 3/10.

User feedback:
- the architecture was understood correctly;
- the visual design itself was poor;
- the result felt aesthetically regressive compared with an earlier assistant-produced aesthetic test in the conversation `Work与Codex区别分析`;
- the user supplied `ink-east-homepage-v1.zip` as concrete evidence of a prior design direction they considered materially better.

## Immediate decision

DO NOT iterate Object Field V1 incrementally.

The current mother direction is visually rejected and should be treated as an internal KILL, not a base for V1.1 polish.

## Why V1 failed

1. The opening fell back into a recognizable luxury-ecommerce formula:
   text block + large product image + secondary thumbnails + CTA.

2. The discovery system was intellectually correct but visually generic:
   `OBJECT / SPACE / MATERIAL` became a tab/panel interface instead of a designed spatial event.

3. Product imagery carried too much of the visual interest.
   Replacing the stock jewelry imagery with ordinary placeholders would expose a weak composition.

4. The page repeated predictable web modules instead of allowing each state to have a distinct composition.

5. Whitespace was mostly spacing, not active structural pressure.

6. The archive transition was functional but not authored enough.

7. The static screenshot lacked a strong design hook and controlled surprise.

## Recalibration benchmark: prior Ink & East homepage concept

The supplied prior concept demonstrates a stronger level of authorship through:
- a decisive asymmetrical first-screen composition;
- layered spatial field / grid / landscape geometry rather than a conventional hero block;
- typography, image/object, line, color and negative space working as one composition;
- strong dark/light/red state changes across the page;
- different sections using variable composition while keeping one system;
- diagrammatic/structural devices used as meaningful spatial language, not UI chrome;
- visual rhythm created by pressure, pause, scale and boundaries;
- static frames that remain strong without relying on motion.

The lesson is NOT to copy Ink & East visually.
The lesson is to restore the level of composition, authorship, spatial pressure and controlled surprise.

## Corrected design process

Before showing the next Shop prototype:

1. abandon the current literal `Object Field -> Archive` layout;
2. keep only the architectural role:
   `light commercial entry + real product archive`;
3. internally develop multiple genuinely different mother compositions;
4. test each with neutral/ordinary product placeholders;
5. reject any candidate that resembles a luxury ecommerce template;
6. reject any candidate whose discovery system looks like tabs/panels/dashboard UI;
7. only show a candidate whose static screenshot has a clear design hook at the same order of ambition as the prior Ink & East aesthetic test.

## Architecture still locked

- DIY light experience homepage: sibling branch at the same level;
