# Project 2 · Footer V2 Trust Rail R3 ultra-light direction · 2026-09-14

## Trigger
User reviewed Footer V2 R2 and asked whether the remaining three-item trust rail could be lighter still.

## Design judgment
Yes. R2 is materially better than the old four-column trust card, but it still reads as a distinct content section because each trust item contains icon + title + explanatory paragraph and the rail has enough vertical height to become a second footer module.

## Locked refinement direction
Keep the commercial trust signals, but demote them to tertiary footer metadata rather than a standalone content section.

Desktop target:
- retain exactly three trust signals: Worldwide Shipping / 30-Day Returns / Authentic Materials;
- remove explanatory paragraphs from the visible default state;
- reduce icon scale and vertical height;
- present all three as a quiet inline micro-rail between primary footer navigation and the legal/bottom row;
- no card treatment, no large borders, no headline block.

Mobile target:
- keep the same three signals;
- stack as very compact rows or a small two-line list;
- avoid adding significant scroll length;
- maintain legibility and touch-safe spacing.

## Content-truth boundary
Any concrete operational claim such as `30-Day Returns` or shipping-time promises must match live Shipping / Refund policy content before production lock. Prototype copy is not production truth by itself.

## Status
Design refinement only. No production source changes authorized yet.
