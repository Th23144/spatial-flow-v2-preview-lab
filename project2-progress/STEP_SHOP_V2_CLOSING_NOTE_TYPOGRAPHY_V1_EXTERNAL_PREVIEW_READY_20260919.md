# Shop V2 — Closing Note Typography V1 external preview prepared

Date: 2026-09-19

## Scope

Prepared one external standalone HTML visual study for the currently reopened Shop Closing Note typography hierarchy.

The preview is intentionally not stored in this repository and does not modify production source.

## What the study preserves

- current open two-column Closing Note concept;
- equal-column structure rather than a new module;
- existing Intro / Emphasis / Body / Side Text / Button ownership model;
- existing CTA function concept;
- warm paper surface and dark Footer transition;
- no cards, no large background panel, no new hero-like section.

## What the study changes visually

Typography V1:
- restores the existing backend-owned Kicker as a quiet section label;
- separates Intro, Emphasis and Body into distinct typographic levels;
- makes Emphasis the main serif/italic anchor;
- reduces Body to supporting copy;
- gives the right-side copy a restrained rule/anchor;
- tightens right-copy measure and CTA grouping;
- removes the concept of desktop right-offset tuning as a solution.

The standalone HTML also includes a Current / Typography V1 toggle so the hierarchy change can be judged directly without presenting multiple competing redesign concepts.

## Important limitation

The right-side paragraph in the external study is representative density copy only. Production must retain the current backend-owned Closing Note Side Text unless the user separately changes that content.
