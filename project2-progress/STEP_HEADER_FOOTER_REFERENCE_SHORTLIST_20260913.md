# Project 2 · Header / Footer external visual-reference shortlist · 2026-09-13

## Purpose
Provide the user with mature real-world visual references before committing to the Spatial Flow Header/Footer redesign. This is reference research only; no live source changes are authorized.

## Curated reference set

### A · FRAMA
Official site: https://framacph.com/
Why relevant:
- unusually close to Spatial Flow's subject matter: objects, spaces, sensory/lifestyle editorial content plus commerce;
- Shop navigation is broad and content-rich, but organized by hierarchy (Featured, product families, By Room, Inspiration, Stories, Visit) rather than presenting raw filter taxonomies as one flat database;
- footer separates Customer Care, Info, Professionals, and Connect rather than trying to put all support destinations into the header;
- useful as the strongest overall IA reference for Spatial Flow.

Traits to evaluate:
- broad Shop navigation hierarchy;
- editorial + commerce coexistence;
- footer category separation and density;
- use of support links in footer instead of primary header.

### B · The Row
Official site: https://www.therow.com/
Why relevant:
- strong luxury/minimal navigation model;
- top-level user utilities include Search, Saved, Login, Bag while a much larger catalog hierarchy lives inside Menu;
- demonstrates that a premium site does not need to expose every destination as a same-weight top-level button.

Traits to evaluate:
- extremely restrained utility navigation;
- menu as a large catalog/navigation layer rather than a floating card;
- low-noise luxury presentation.

### C · TOTEME
Official site: https://toteme.com/
Why relevant:
- minimal commerce shell with Search / Account / Bag utilities;
- footer is clearly divided into Legal, Contact, About, Follow and mailing-list areas;
- useful reference for a very restrained header and a structured but not decorative footer.

Traits to evaluate:
- sparse header utilities;
- footer information grouping;
- separation of service/support from primary product navigation.

### D · Zara Home
Official site: https://www.zarahome.com/ww/
Why relevant:
- large lifestyle/home catalog with strong editorial sub-navigation;
- navigation mixes product categories with editorial/collection concepts;
- useful as a reference for how a content-rich Shop can expose many destinations without treating them as raw filter dimensions.

Traits to evaluate:
- editorial categories inside commerce navigation;
- handling of a large catalog;
- distinction between shop taxonomy and editorial discovery.

## Preliminary synthesis for Spatial Flow
Do not copy any one reference literally. Candidate synthesis after user preference selection:
- FRAMA for Shop information architecture and Footer grouping;
- The Row for low-noise luxury shell / utility restraint;
- TOTEME for footer clarity;
- Zara Home only where Spatial Flow needs richer editorial discovery.
