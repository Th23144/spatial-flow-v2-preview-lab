# Project 2 · Header V2 visual prototype start · 2026-09-13

## User direction
The user does not want to continue reviewing external reference sites one by one. Header/Footer should be judged mainly by fit with Spatial Flow, mature information architecture, complete entry points, responsive behavior, and production quality.

## Current action
Create an independent visual prototype outside the repository and outside the live WordPress theme. The prototype must not modify production files.

Prototype scope for this step:
- Desktop header
- Shop mega menu
- Tablet header state
- Mobile header and grouped drawer
- Responsive width behavior
- Search / Saved / Bag utility placement

Footer is intentionally deferred to a separate prototype after the Header direction is reviewed.

## Current constraints
- preserve WordPress menu ownership in eventual implementation
- preserve WooCommerce taxonomy data ownership for Shop discovery
- do not add Checkout as a permanent global navigation item
- near-full-width header shell rather than ordinary content-container width
- use Spatial Flow paper/ink/editorial visual language
- no live-site code changes in this prototype step

## Separate later step
WordPress Pages / Appearance > Menus admin cleanup remains a separate inventory and hygiene audit. Do not delete pages or menus during Header prototype work.
