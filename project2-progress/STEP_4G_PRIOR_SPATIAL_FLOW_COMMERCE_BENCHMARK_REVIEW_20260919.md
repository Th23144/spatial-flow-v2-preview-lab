# Step 4G — Prior Spatial Flow commerce concept review: break self-imposed visual constraints

Date: 2026-09-19
Repository: `Th23144/spatial-flow-v2-preview-lab`

## New user-supplied benchmark

The user supplied `spatial-flow-commerce-v1.zip`, a prior concept produced in another conversation by the same model.

This reference is especially important because it proves:
- the stronger design level is compatible with Spatial Flow itself;
- the problem in the rejected Shop Hybrid V1 was not the brand palette or Project 2 constraints;
- the failure came from narrowing the existing Spatial Flow language into a conservative ecommerce-template interpretation.

## What the supplied concept demonstrates

### 1. Composition before modules
The first screen is not a standard ecommerce hero.

It uses:
- a split spatial field;
- large controlled negative space;
- asymmetric text/object balance;
- a still-life object construction;
- thin structural boundaries;
- small vertical metadata;
- one restrained entry action.

The page reads as one composition rather than a collection of UI blocks.

### 2. Site-native color can still carry strong authorship
The concept stays close to Spatial Flow-compatible tones:
- warm paper;
- near-black;
- muted sage/stone;
- restrained clay accents.

Its visual strength comes from proportion, field geometry, object placement, scale and rhythm—not loud color.

### 3. Variable composition across sections
The page does not repeat one section template.

Examples:
- opening field;
- manifesto-like oversized type field;
- selected objects;
- dark spatial philosophy band;
- material index;
- journal field;
- circular closing statement.

These sections differ substantially while sharing the same design grammar.

### 4. Objects are used compositionally
The rendered mineral/bracelet/botanical forms are not simply product cards.
They help establish:
- weight;
- distance;
- material logic;
- field relationships.

### 5. Whitespace has structure
The empty areas are activated by:
- split planes;
- alignment;
- border lines;
- object offset;
- large text placement;
- asymmetrical weight.

This is materially stronger than merely increasing margins.

### 6. Controlled surprise comes from section logic
The visual reward comes from how the page changes state as the user scrolls:
- light spatial field;
- editorial statement;
- product field;
- dark room statement;
- material index;
- journal;
- quiet closure.

It does not rely on tabs/panels/hover tricks to manufacture "interaction."

## What should NOT be copied literally into the Shop hybrid

This concept behaves more like a broad commerce/brand landing page than the current Shop branch.

Do not automatically carry over:
- Journal as a large Shop-owned section;
- broad brand manifesto responsibilities that belong above Shop;
- all material/editorial sections;
- exact split hero geometry;
- exact abstract object illustrations;
- exact section order.

The reference is a QUALITY / COMPOSITION benchmark, not the final Shop IA.

## Corrected mental model

The next Shop candidate should combine:

### From this supplied concept
- composition ambition;
- site-native palette;
- active whitespace;
- variable composition;
- authored static frames;
- object/space relationships;
- strong section rhythm.

### From current Project 2 Shop
- real WooCommerce product archive;
- accepted Filter / Sort;
- accepted product cards;
- accepted pagination;
- accepted Closing Note;
- dynamic ownership and backend editability.

### From current architecture
- Shop is a light commercial branch;
- DIY light experience is a sibling branch;
- neither owns the other;
- global Home remains deferred.

## Critical correction

Do not let "preserve Spatial Flow consistency" mean:
- reuse existing page formulas;
- remain conservative;
- keep the same hero/card/module vocabulary.

Consistency should mean:
- palette discipline;
- typography discipline;
- object treatment;
- spacing logic;
- interaction weight;
- shared creative point of view.

SAME SYSTEM != SAME COMPOSITION.
