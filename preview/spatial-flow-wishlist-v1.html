When the list is empty.

The live empty-state can stay gentle and editorial: no pressure, no urgency, just a clear path back to the shop. This block is included so the later WordPress skin can cover both saved and empty wishlist states.

01 · Privacy

A list should feel private.

Keep wishlist language simple. Saved products are a memory aid, not a sales pressure mechanism.

02 · Product logic

The plugin keeps the state.

Live add, remove and stock behavior should stay controlled by WooCommerce and the wishlist plugin.

03 · Return path

Always leave a way back.

Customers should be able to return to the shop, view a product, or move a saved piece into the bag without visual noise.
